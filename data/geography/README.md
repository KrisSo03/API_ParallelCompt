# Fronteras de Centroamérica

El recurso incluido en
`src/renewable_atlas/infrastructure/grid/data/central_america.geojson` contiene
únicamente los polígonos de Guatemala, El Salvador, Honduras, Nicaragua,
Costa Rica, Panamá y Belice.

- Fuente: Natural Earth, `Admin 0 – Countries`.
- Escala: 1:10 millones.
- Versión: 5.1.1.
- Archivo de origen: `ne_10m_admin_0_countries`.
- Licencia: dominio público.
- Sitio oficial: https://www.naturalearthdata.com/
- Descarga oficial: https://naciscdn.org/naturalearth/10m/cultural/ne_10m_admin_0_countries.zip
- Fecha de extracción: 2026-08-12.

El archivo reducido se conserva dentro del repositorio para que la generación
de puntos sea reproducible y no dependa de acceso a Internet en Kabré.
